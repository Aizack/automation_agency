# Especificación 01: Protocolo de Desarrollo Paso a Paso

1. Sincronizar memoria (`context.md`).
2. Clasificar tarea y asumir rol de Agente.
3. Inspeccionar archivos empíricamente.
4. Proponer plan de cambios.
5. Desarrollar modularmente.
6. Ejecutar verificación / tests.
7. Actualizar `context.md`.
